# Frontend (React + TypeScript + Vite)

Uruchamiany z korzenia repozytorium przez `docker compose` (patrz README w korzeniu).

- `npm install` - zaleznosci (wygeneruje `package-lock.json`, zacommituj go)
- `npm run dev` - serwer Vite (proxy /api do backendu: zmienna `API_PROXY_TARGET`)
- `npm run typecheck`, `npm test`, `npm run build`
